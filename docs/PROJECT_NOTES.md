# Project notes for viva
- Topic: Road Accident Analysis in India.
- Data: state-wise reported accidents, 2020–2024.
- Python handles data preparation and the Flask API.
- R demonstrates ETS forecasting, but only five annual points are available; call this exploratory.

- Primary citation: PRS India transport brief, Table 15, citing MoRTH.
